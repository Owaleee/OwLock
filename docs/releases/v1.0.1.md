# OwLock 1.0.1 — Correção do "Iniciar com o Windows"

## Correções

- Mudar qualquer opção da seção **Área de trabalho** (em Ajustes) não regrava mais o "Iniciar com o Windows" sem necessidade. Antes, quem usava mais de um cofre (opção `--vault`) podia ter a inicialização trocada para o cofre errado.

## Também nesta versão

- README com imagens do app (feitas com um cofre de demonstração, com dados fictícios).

## Download

- **`OwLock-Setup.exe`** — recomendado. Para atualizar, é só rodar por cima da versão instalada; o cofre não é alterado.
- **`OwLock.exe`** — versão portátil, sem instalação.

Os hashes SHA-256 estão no `SHA256SUMS.txt`.
